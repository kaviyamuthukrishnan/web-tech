Observing Internet Protocols Using DevTools

Web Technology Lab Exercise - Network Tab Analysis

Step-by-Step Instructions

  1. Open this page in Chrome or Edge.
  2. Press F12 (or right-click → Inspect) to open Developer Tools.
  3. Click the Network tab.
  4. Refresh the page (Ctrl+R / Cmd+R) with the Network tab open so it captures every request from the start.
  5. Click the "Load Extra Resource" button below to trigger one more request.
  6. For each row in the Network tab, note: Name/URL, Protocol, Method, Status, Type, Size, Time — this page loads a font, a script, an image, and (on button click) an XML file, giving you a mix of resource types to observe.
Tip: The "Protocol" column may be hidden by default. Right-click any column header in the Network tab and enable "Protocol" from the checklist to reveal it (it will typically show h2 or http/1.1).

Key Terms for Your Lab Report

TermMeaning
ProtocolThe rule set used to transfer data (e.g. HTTP/1.1, h2 for HTTP/2, h3 for HTTP/3)
MethodThe action requested — GET (retrieve data) or POST (send data) are most common
Status CodeServer's response code — 200 (OK), 304 (Not Modified/cached), 404 (Not Found), 500 (Server Error)
TypeThe kind of resource — document, stylesheet, script, image, xhr/fetch, font
SizeData transferred, often shown as "transferred / actual resource size"
TimeHow long the request took, from send to full response

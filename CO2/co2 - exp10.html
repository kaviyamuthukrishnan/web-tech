Bug 2 — JavaScript: Button Click Doesn't Work

Clicking LOGIN does nothing. Open the Console tab and check whether addEventListener() was ever attached.

Live Preview

💡 Hint: Use console.log() inside the click handler to check if it even fires. If nothing logs, the listener was never attached — or attached to the wrong element ID.
// ❌ Wrong ID — listener never attaches to the real button
const btn = document.getElementById('loginBtn');
btn.addEventListener('click', function() {
  console.log('Login clicked');
});
// ✅ Correct ID matches the actual button
const btn = document.getElementById('brokenLoginBtn');
btn.addEventListener('click', function() {
  console.log('Login clicked');
  document.getElementById('loginStatus').textContent = '✅ Logged in!';
});

Bug 3 — Runtime Error: App Crashes on Click

Clicking "Load Profile" throws an error because the code tries to read a property from undefined. Wrap it safely using try...catch.

Live Preview

// console output appears here
💡 Hint: Open the Console panel — an uncaught TypeError stops the whole script. A try...catch block lets you handle it gracefully instead of crashing.
// ❌ No error handling — this throws and stops execution
function loadProfile() {
  const user = undefined;
  console.log(user.name); // 💥 TypeError
}
try {
  const user = undefined;
  console.log(user.name);
} catch (error) {
  console.log('Caught error:', error.message);
}

Bug 4 — Logic Error: Wrong Calculation

This calculator always shows the wrong total. There's no crash and no console error — the code runs fine, it's just wrong. Use debugger; and step through with breakpoints to catch it.

Live Preview

Cart: 3 items × ₹150 each

Calculating...
💡 Hint: Set a breakpoint (or add debugger;) right before the return statement, then inspect each variable's value in the Sources panel — one of them is not what you'd expect.
function calculateTotal(qty, price) {
  debugger; // pause here and inspect qty & price
  let total = qty - price; // ❌ wrong operator
  return total;
}
function calculateTotal(qty, price) {
  let total = qty * price; // ✅ correct operator
  return total;
}
